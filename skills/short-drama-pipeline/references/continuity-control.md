# 连续性控制（场记手册）

AI 生成最贵的不是算力，是"同一集里角色变脸、雨衣变款、头盔变型、道具凭空出现/消失"。本手册把连续性从"靠眼睛看"变成"状态机 + 镜头契约 + 边界表"。

## 一、三条铁律

1. **单一事实源**：角色卡 > `01_series/continuity/contracts.yaml` > 分镜 prompt。三处冲突时停下，先改上游，不允许在 prompt 里"就地打补丁"。
2. **状态显式**：每个镜头必须写清 `state_in`（继承上一镜）和 `state_out`（本镜结束）。没有写状态，就等于允许模型自由发挥。
3. **变化必须被镜头看见**：角色摘头盔、换手、换服装、添新伤，必须有一个镜头完成这个动作；不允许在剪辑点之间"悄悄变"。

## 二、状态变量

每个变量有固定取值。未列出的值视为非法，机检直接报错。

| 变量 | 归属 | 示例取值 | 变化规则 |
| --- | --- | --- | --- |
| `wardrobe` | 角色妆造 | `raincoat_037` / `hoodie_only` / `raincoat_off` | 只能在同一场或时间跳跃后变；换装必须有镜头 |
| `helmet` | 角色妆造 | `worn_open_face` / `off_right_hand` / `off_left_hand` / `on_bike` / `none` | 戴/摘必须有动作镜；持盔统一右手，左手例外要登记 |
| `injury` | 角色妆造 | `old_scar_only` | 本剧只允许一处旧疤；新伤必须由剧情产生并登记 |
| `wetness` | 角色妆造 | `dry` / `damp` / `soaked` | 只增不减；进屋后从 `soaked` 到 `damp` 需时间跳跃或擦水镜头 |
| `held_left` | 角色妆造 | `none` / `phone` / `cup` / `bag` / `receipt` | 左手固定拿手机；交接必须有动作 |
| `held_right` | 角色妆造 | `none` / `helmet` / `cup` / `bag` / `receipt` | 持盔统一右手；不得与手机同手 |
| `props` | 美术道具 | `cup: present` / `cup: absent` / `phone: present` | 道具不能凭空出现；数量按集数进度 |
| `time` | 场景 | `夜` / `深夜` / `清晨` | 跨时间必须 `time_jump` |
| `weather` | 场景 | `暴雨` / `雨后` / `雨停` | 雨势单调递增（第 12 集才停） |
| `axis_side` | 分镜/摄影 | `A` / `B` | 同场不越轴；越轴必须有中性镜或新场 |
| `screen_direction` | 分镜/摄影 | `left_to_right` / `right_to_left` | 同场运动方向不得无故反转 |

## 三、镜头契约

每个镜头在 `shotlist/epNN.yaml` 里至少写清：

```yaml
- id: ep02_s007
  duration: 3.5
  shot_type: MS
  camera: "固定，略低机位"
  axis_side: A
  characters: [chenmo]
  beat: "他把冰袋放在桌上，发现袋底贴着一张外卖小票"
  state:
    chenmo:
      wardrobe: raincoat_037
      helmet: off_right_hand
      injury: old_scar_only
      wetness: soaked
      held_left: none
      held_right: helmet
  props:
    cup: absent
  transition:
    type: cut
    motivated_by: "同一动作的下一拍，时间连续"
  refs:
    - 03_keyframes/ref/chenmo_ref_v2.png
  prompt: "<角色锚点逐字复用> + 画面/动作"
  negative: "<角色负面词逐字复用>"
  acceptance:
    - "右手持半盔，贴纸朝后不可见"
    - "雨衣左胸 037 可见，只有一处"
```

字段说明：

- `state` 按角色分组；未写的变量继承 `scenes[].state_defaults`。
- `props` 写本镜可见/不可见的关键道具；`present` 的必须在 prompt 里出现道具锚点。
- `transition.type` 只能是：`open`（场首）、`chain`（尾帧接力）、`cut`（同时空切）、`match_cut`（形状/动作匹配）、`insert`（插入特写）、`state_change`（本镜完成状态变化）、`time_jump`（时间跳跃）。
- `transition.motivated_by` 在状态或轴线变化时必填。

## 四、转场规则（机检可执行）

| 类型 | 状态要求 | 轴线要求 | 用途 |
| --- | --- | --- | --- |
| `open` | 场首，允许重置 | 新场可换侧 | 新场第一镜 |
| `chain` | 必须与上一镜完全一致 | 必须同侧 | 同场景连续动作，尾帧接力 |
| `cut` | 必须与上一镜一致 | 同侧；越轴需 `motivated_by` | 同时空切换景别/角度 |
| `match_cut` | 必须一致 | 可同侧或中性 | 形状/动作匹配转场 |
| `insert` | 必须一致 | 不适用 | 插入特写（手、道具、屏幕） |
| `state_change` | 必须至少一个变量变化 | 同侧 | 摘头盔、换手、穿衣、添伤 |
| `time_jump` | 允许重置，但需写清新状态 | 可换侧 | 跨时间/跨地点 |

**禁止**：`cut`/`chain`/`insert` 里出现未登记的状态变化；`state_change` 里状态没变；同场 `axis_side` 从 A 翻到 B 却没有中性镜或 `motivated_by`。

## 五、动态一致性（切镜不跳戏）

1. **屏幕方向**：同场角色/车辆的运动方向保持一致；从 `left_to_right` 切到 `right_to_left` 必须有掉头、反打或新场。
2. **动作接动作**：优先在动作中段切（cut on action），下一镜从同一动作的延续开始；上一镜尾帧与下一镜首帧的手臂/道具位置要对得上。
3. **速度连续**：相邻镜的运动速度差不超过一档；慢镜头后不能直接接正常速度，除非有节奏意图并登记。
4. **视线匹配**：A 看画右，B 的反打应看画左；视线高度差要与机位一致。
5. **入出画**：角色从画左出，下一镜应从画右入（同场同方向）；不能从同一侧再次入画。
6. **AIRLOCK 本地口径**：15 秒分段（3×5.17s 续写）段首保留约 2 秒稳定构图；5.17 秒单镜压到 0.3–0.8 秒真人微动，不是静帧。段尾回到稳定构图，台词不跨段。
7. **尾帧接力**：同场连续镜头优先 `chain_from`；换场或时间跳跃才重新起关键帧。接力镜的 `last_frame` 必须是上一镜真实末帧，不能用首帧冒充。

## 六、人物与妆造

- **锚点逐字复用**：角色卡里的英文锚点整段复制，不改写、不缩写、不换同义词。改一个词就可能换一张脸。
- **参考图层级**：角色三视图（正/侧/三分之四）> 定妆全身 > 单镜关键帧。每个镜头至少带一张角色参考；不许只靠文字"记得像"。
- **疤痕/伤口**：写明"old pale scar"而不是"scar"；写明位置（面对镜头时画面右侧）；负面词写"no fresh wound / no blood / no second scar"。
- **妆造进度**：雨水、泥点、汗、血迹只能随剧情累积；不能上一镜湿透、下一镜干爽。换装/擦水/包扎都要有镜头。
- **头盔/帽子**：类型、颜色、贴纸位置、系带状态写进契约；正面镜头不能让贴纸出现，背面镜头必须出现。
- **发型**：戴盔后头发压痕、淋雨后刘海状态属于连续性；跨镜不能一会儿干一会儿湿。

## 七、道具

- 每个关键道具建一张卡：`id / 名称 / 尺寸锚 / 材质 / 颜色 / 文字策略 / 持有手 / 出现集`。
- prompt 里写"约手掌高、500ml 封口透明杯、圆顶盖、吸管、空白矩形标签"，不写品牌。
- 文字、单号、平台 UI 一律后期叠层；生成画面只留空白标签/空白屏幕。
- 道具不能凭空出现或消失；数量按剧情进度（如奶茶杯数=集数）。
- 同一道具在不同镜的尺度要一致：用身体部位做锚（杯高≈手掌长，头盔≈头围+两指）。

## 八、场景与光线

- 每个场景建场景卡：地点、时间、天气、光源、色温、主色、机位侧、参考图。
- 同场光线方向固定；换场才换光。雨夜戏的钠灯/霓虹反光位置要逐镜一致。
- 场景里的家具/招牌/车辆位置属于连续性；背景大物件不能在切镜后换边。
- 雨势、积水、雾气按集数递进；不能随机晴雨。

## 九、AI 特有失败与对策

| 现象 | 根因 | 最便宜修法 | 预防 |
| --- | --- | --- | --- |
| 角色变脸 | 锚点被改写/参考图缺失 | 单镜重生成 | prompt 锁 + 每镜带参考图 |
| 雨衣变款/037 消失 | 长 prompt 被模型忽略 | 单镜重生成 + 负面词 | 锚点前置、编号单独强调 |
| 头盔变全包/出现面罩 | 模型先验 | 单镜重生成 | 正面写 open-face、负面写 full-face/visor/chin bar |
| 疤换边/变新伤 | 左右描述歧义 | 单镜重生成 | 写"画面右侧"、old pale scar、负面 no fresh wound |
| 道具多出/消失 | 场景元素被重绘 | 后期遮罩或单镜重生成 | 道具卡 + 接触表逐镜核对 |
| 手指/肢体异常 | 模型极限 | 换机位/遮挡/后期 | 负面词 + 关键帧目检 |
| 画面内出现文字/logo | 模型先验 | 后期覆盖/重生成 | negative + 空白标签策略 |
| 背景穿帮（现代物件/品牌） | 场景参考不足 | 重生成或裁切 | 场景卡 + 参考图 |
| 切镜后运动方向反转 | 未守 180° 轴线 | 调整机位或加中性镜 | axis_side + 分镜会 |
| 切镜后动作不接 | 未做尾帧接力 | 补尾帧/重跑下一镜 | chain_from + 边界表 |

## 十、质检门与返工决策

| 门 | 检查 | 工具 | 不通过 |
| --- | --- | --- | --- |
| G2 契约 | 字段齐全、状态闭合、锚点逐字、时长闭合 | `check_continuity.py` | 退回分镜 |
| G3 关键帧 | 24 帧接触表：角色/妆造/道具/场景/文字 | `--sheet` + 人检 | 单镜重生成 |
| G4 视频 | 首尾帧边界表：动作/方向/道具/曝光 | `--video-sheet` + 人检 | 单镜重跑 |
| G5 成片 | 切点逐一对账、字幕、响度、黑帧 | 剪辑自检 + QA | 退回剪辑 |

返工优先级（从便宜到贵）：

1. **后期能修**：文字、logo、小穿帮、颜色偏差 → 遮罩/调色/叠层。
2. **插入镜**：状态变化缺镜头 → 补一个 1–2 秒 insert，不重跑整段。
3. **单镜重生成**：角色/服装/道具错 → 只重跑该镜，seed 记录变更。
4. **改分镜**：叙事本身不成立 → 回 G2，禁止在生成端硬救。
5. **改资产**：角色锚点/场景卡错 → 回 G0，全季影响，必须总导演签字。

## 十一、可选：本地 VLM 预检

本机有 Qwen2.5-VL-7B（GGUF/FP8）与 Florence2 节点，可对关键帧做**只读预检**：把图 + 检查清单喂给 VLM，输出 JSON（角色数、头盔类型、疤的位置、雨衣编号、道具数量、画面文字）。它只用于排序和预警，**不能替代人检与接触表**；VLM 报错不等于真错，VLM 通过也不等于可交付。

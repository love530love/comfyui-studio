# 发布登记与合规

## 授权边界

- 上传、发布、定时发布、修改可见性都是对外可见动作，**必须由用户逐次显式授权**。
- 未获授权时只做本地准备：成片、封面、标题、话题、简介、发布登记草稿。
- 不把用户的账号密码、cookie、验证码写入任何项目文件或日志。

## 发布登记（`08_publish/epNN.md`）

```markdown
# 第 N 集 发布登记
- 标题: <平台标题，含钩子不超 30 字>
- 话题: #漫剧 #反转 #...
- 封面: 03_keyframes/epNN/cover.png
- 成片: 07_exports/epNN.mp4
- 时长: 78.4s
- AI 内容标识: 已开启 / 平台要求项
- 平台: 抖音漫剧
- 状态: draft | uploaded | scheduled | published
- 平台作品 id: <发布后回填>
- 发布时间: <ISO 时间>
- 授权记录: <用户授权原话与时间>
```

## 抖音漫剧平台流程骨架

以下为待实测校正的骨架。首次执行时用 `ai-browser-bridge`（用户已登录的 Chrome），按"健康检查 → 列标签页 → 读页面 → 定位 → 校验后点击"的顺序操作：

1. 打开创作者中心，确认作品管理入口与上传按钮位置。
2. 上传成片，等待转码完成；核对标题、封面、简介、话题。
3. 设置 AI 生成内容标识（平台有此选项时必须开启）。
4. 选择定时或立即发布，**在点击最终发布前向用户复述全部字段并取得确认**。
5. 发布后回填作品 id 与链接到 `08_publish/epNN.md`。

任何一步的页面结构与本文不符，以页面实际内容为准，并更新本节。

## 内容红线

- 不使用未授权的真人肖像、影视片段、音乐。
- 暴力、血腥、恐怖镜头控制强度，按平台规则自查。
- 涉及真实机构、品牌、事件的设定做架空化处理。
- 成片与封面不出现第三方水印。

## 失败处理

- 上传中断：重新观察页面状态，确认是否已生成草稿，禁止盲目重复上传。
- 审核驳回：记录驳回原因到登记文件，修改后重新走授权流程。
- 结果不明（点击后页面无反馈）：先只读核查作品列表，不重复提交。

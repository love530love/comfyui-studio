# 角色一致性参考

跨镜头的角色外观必须由**固定的文字描述 + 固定参考图**共同锁定，不依赖模型"自由发挥"。

## 角色卡

每个主要角色在项目目录 `02_characters/<name>.md` 建档，至少包含：

```markdown
# 角色名
- 年龄 / 性别
- 发型发色（逐字复用）
- 眼睛（颜色、形状）
- 服装（每套一个编号）
- 标志物（疤痕、饰品、纹身）
- style tag（画风锚点）
- reference_image: 03_keyframes/ref/<name>_ref_v1.png
```

`prompt` 中的角色段落直接从角色卡复制，禁止同义改写。"黑色长直发"不能写成"乌黑长发"，两种写法会让模型给出不同脸型。

## 参考图生成

1. 第一版角色立绘：用 Z-Image Turbo 生成 3–5 张候选，人工选定 1 张。
2. 定妆后把小图放大并存入 `03_keyframes/ref/`，命名带版本号（`_ref_v1`、`_ref_v2`）。
3. 后续镜头改用图生图节点：
   - Qwen-Image-Edit：适合表情、服装微调；
   - Flux Kontext：适合构图迁移；
   - 角色 LoRA：大批量、长期项目才考虑训练。
4. 图生图工作流必须通过 `get_object_info` 查询节点必填参数后再提交。

## 检查规则

- 同一集内每个镜头提交前，比对角色卡字段是否全部出现在 prompt 里。
- 生成后按"发色 / 服装编号 / 标志物"三项核对；任一项不符，标记该镜头重跑，不进入剪辑。
- 参考图换版本时，同集已生成镜头要评估是否统一重跑，并在分镜表标注版本号。

## 禁止做法

- 不要靠 seed 相同实现一致性：换提示词或换分辨率后 seed 不再保证外观。
- 不要混用不同风格 tag（如同时出现 `photorealistic` 与 `anime`）。
- 不要把多角色塞进同一提示词再靠裁切分离，人物会互相污染特征。
